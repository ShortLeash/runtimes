# "#" reason. php.sh drops them from php-extensions.txt's list (and from its
# check that every listed extension loaded) for a pre-release version only.

# once a release of the extension builds, and empty the file when the minor
# is released. Checked against PHP 8.6.0RC3 with static-php-cli 2.8.5 and
# PECL's releases on 2026-10-19; most use macros PHP 8.6 removed (XtOffsetOf,
# zval_dtor, INI_STR, INI_INT and INI_BOOL).
